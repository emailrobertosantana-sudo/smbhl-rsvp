# Ad test links

Six homepage links for the first ad test (campaign test1), one per angle and
language. Each opens the homepage with its hero (the `a` parameter) and
carries the utm_ parameters through sign-up to the new league
(`src/attribution.js`). The super-admin league list shows them per league and
counts leagues created and first invites sent per `utm_content`.

French, angle "comptes" (no account, no app):
https://notreligue.ca/fr?a=comptes&utm_source=facebook&utm_medium=paid&utm_campaign=test1&utm_content=comptes-fr

French, angle "remplacants" (subs invited automatically):
https://notreligue.ca/fr?a=remplacants&utm_source=facebook&utm_medium=paid&utm_campaign=test1&utm_content=remplacants-fr
